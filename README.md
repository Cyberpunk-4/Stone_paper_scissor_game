# ✊🖐✌ Stone Paper Scissors Game

## 📌 Description

The Stone Paper Scissors Game is a simple and interactive web-based application that allows users to play the classic game against the computer. The user selects one of the three options—stone, paper, or scissors—and the computer randomly generates its choice. The result is then displayed instantly based on the game rules.

This project demonstrates the use of basic programming logic, event handling, and DOM manipulation to create a fun and engaging user experience. It is beginner-friendly and helps in understanding core concepts of JavaScript and front-end development.

---

## 🚀 Features

* 🎮 Play against computer
* 🔀 Random computer choice generation
* ⚡ Instant result display (Win/Lose/Draw)
* 🧠 Score tracking system
* 📱 Responsive and simple UI
